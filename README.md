# LFSSR_LapDR

This is the PyTorch implementation of “Progressive Heterogeneous Light Field Spatial Super-Resolution With Deformable Attention and Information Distillation”.

# Usage
You can use the released code to train or test your own model.

For 8× SR
1. run './LFSSR_LapDR_master_x8/train.py' to train your own model.
2. run './LFSSR_LapDR_master_x8/test.py' to test the pre-trained model.

For 4× SR
1. run './LFSSR_LapDR_master_x4/train.py' to train your own model.
2. run './LFSSR_LapDR_master_x4/test.py' to test the pre-trained model.

The pre-trained model (8x and 4x) can be downloaded via Baidu Drive：[https://pan.baidu.com/s/1cYrV5BvvjHijtYVr6CWNhQ](https://pan.baidu.com/s/1iOxSzh4wqaF3yY_6aHnjtw?pwd=vcnn) (key: vcnn)
