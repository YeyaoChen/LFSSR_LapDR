# LFSSR_LapDR

This is the PyTorch implementation of “Progressive Heterogeneous Light Field Spatial Super-Resolution with Deformable Attention and Information Distillation”.


You can use the released code to train or test your own model.

For 8× SR

run './8x/train.py' to train your own model.
run './8x/test.py' to test the pre-trained model.
For 4× SR

run './4x/train.py' to train your own model.
run './4x/test.py' to test the pre-trained model.
The pre-trained model (8x and 4x) can be downloaded via Baidu Drive：https://pan.baidu.com/s/1cYrV5BvvjHijtYVr6CWNhQ (key: SAPE)
